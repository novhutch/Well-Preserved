StoryRoots Project

StoryRoots: Mapping Savannah's History is a community-driven project run by the City of Savannah Municipal Archives to document places of historical significance across the city as remembered and shared by residents. Community members submit locations through an online form, along with their own photos and related materials, and the Archives is using those contributions to build an interactive public map of the sites, memories, and moments that have shaped Savannah — with public input also helping guide how the Archives preserves and shares that history going forward.
