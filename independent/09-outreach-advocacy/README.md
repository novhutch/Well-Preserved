# 09 — Outreach and Advocacy
**Tags:** outreach, community archives

Hands-on artifacts for the Outreach and Advocacy competency: curated display photographs and the StoryRoots project.

**What this shows I can do:**

Translate archival holdings into public-facing exhibits — selecting and presenting material from the collections for a general audience, not just for researchers who already know what they're looking for.

Contribute to community-facing programming that invites the public to help build the historical record, rather than only preserving material the archives already holds.

Communicate archival work to non-specialist audiences, using accessible framing instead of professional/archival language.

Support advocacy for community and civil rights history by helping make it visible outside the reading room.

Work across two different outreach formats — a static physical/photographic display and an ongoing, interactive public history project — showing range in how outreach can be done.
