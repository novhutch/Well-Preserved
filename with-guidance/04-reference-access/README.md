# 04 — Reference and Access
**Tags:** outreach

Coursework artifact for the Reference and Access competency: a Patron Relations presentation.

**What this shows I can do:**

Think through reference service from the patron's side — anticipating the questions, friction points, and expectations a researcher brings to an archives, not just the internal workflow for handling them.

Present service standards and procedures in a format meant to train or inform others, not just document them for my own use.

Balance access with the archives' other obligations — showing awareness of when open access is appropriate and when a request needs limits (restricted materials, donor conditions, capacity).

Communicate policy and procedure clearly to a non-archivist audience, a core reference-desk skill.
