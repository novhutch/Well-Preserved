# Portfolio Documentation

Five documents that explain how this portfolio was selected, managed, protected, and made accessible. They are not tied to one competency; they support the whole portfolio.

**What this shows I can do:**

Point a reader to the evidence for each of the course's scoring criteria.

Explain what I chose to include, what I left out, and what that choice makes invisible.

Plan and track a project, including time and risks.

Apply the SAA Code of Ethics to real decisions, and document permissions for the materials I share.

Test whether the portfolio survives outside GitHub, and keep a record of the results.

Find and fix accessibility problems, and keep a log of each fix and why it matters.

**Documents:**

- [Evidence Map](Evidence-Map_v1.0_2026-10-24.pdf) — where to find the evidence for each scoring criterion
- [Planning Notes](Planning-Notes_v1.0_2026-10-24.pdf) — how I chose what goes in the portfolio, and how I managed building it
- [Ethics and Permissions](Ethics-and-Permissions_v1.0_2026-10-24.pdf) — ethical decisions tied to the SAA Code of Ethics, and permissions for shared materials
- [Preservation and Export Log](Preservation-and-Export-Log_v1.0_2026-10-24.pdf) — how the portfolio is protected, copied, and tested outside GitHub
- [Accessibility Remediation Log](Accessibility-Remediation-Log_v1.0_2026-10-24.pdf) — accessibility problems found, fixes made, and why each matters
